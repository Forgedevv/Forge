# 02 — TEMPLATE (agent 2)

**You own**: `apps/launchpad-template`, **except** the visual zone (`src/theme`, `src/content`, `src/components`, layout of `src/pages`), which belongs to agent 6 (frontend, see `docs/frontend/`). Yours: `src/forge/`, `src/pages/api/`, reading `forge.config.json`, `next.config`, `package.json`, the scripts. Your `src/forge/` components expose their styles through the theme's CSS variables (`docs/frontend/SCREENS.md`, part B) so that agent 6 can style them without modifying them.
**You read**: `PLANEXECUTE.md`, `docs/METEORA.md` (template, Jupiter, platform fee sections), `docs/INTERFACES.md` (section 3, forge.config.json), `docs/SECURITY.md` (section 1), `docs/PRODUCT.md`.

You build the site that each client receives. The builder agent will then modify the design of each copy: your structure must make it **impossible** to touch the money logic without breaking the scan.

## Starting point

Copy `scaffolds/fun-launch` from https://github.com/MeteoraAg/meteora-invent into `apps/launchpad-template` (keep the license and attribution).

## Required structure

```
apps/launchpad-template/
├── forge.config.json            # generated by the builder (see INTERFACES.md §3)
├── src/forge/                   # LOCKED ZONE: the builder agent never touches it
│   ├── BuyButton.tsx            # buy/sell before graduation via @forge/core
│   ├── JupiterTrade.tsx         # Jupiter plugin after graduation, with integrator fee
│   ├── TradePanel.tsx           # picks BuyButton or JupiterTrade depending on isGraduated
│   ├── ClaimCreatorFees.tsx     # fee claiming for coin creators
│   ├── CreateCoin.tsx           # coin creation (reuses fun-launch logic, launchpad config)
│   ├── config.ts                # reads forge.config.json#onchain, validates with zod
│   └── security-headers.ts      # CSP, used by next.config
├── src/theme/                   # FREE ZONE: colors, fonts, visual components
├── src/content/                 # FREE ZONE: texts, "about" pages, FAQ
└── src/pages, src/components    # existing fun-launch, wired to src/forge for everything money-related
```
